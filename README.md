# Antik Harita Türkiye

Android için tarihî/arkeolojik yerleşim atlası ve kültür varlığı koruma/bildirim uygulaması.

Bu depo, GitHub Actions ile otomatik debug APK üretir. APK indirmek için **Actions → Android APK Build → son başarılı çalışma → Artifacts → antik-harita-turkiye-debug-apk** yolunu kullanın.

## Özellikler
- Yakınlaştırılabilir Türkiye haritası
- Antik/güncel ad ve mevki bilgileri
- Dönem, tür ve güven filtreleri
- GPS ve çevredeki kamuya açık arkeolojik kayıtları tarama
- Potansiyel araştırma bölgeleri (hassas/yayımlanmamış hedef koordinatları içermez)
- Favoriler ve saha kayıtları
- PIN korumalı özel kayıt alanı
- JSON/CSV yedek ve PDF bildirim raporu

## Güvenlik
Korunması gereken gizli/yayımlanmamış arkeolojik alanlar hassas kazı/define hedefleri olarak sunulmaz. Potansiyel kayıtlar yaklaşık araştırma bölgeleri olarak gösterilir.
