# R2544.19 Case Memory + Provenance Research

## Goal

R2544.19 does not create a new autonomous trading strategy. It improves the truth supplied to JEV and the way measured outcomes are remembered. JEV remains the final strategic authority; deterministic execution safety remains downstream and unchanged.

The central rule is **entry state → path → outcome**, not “one winning/losing setup becomes a rule”. Each live BrainHub entry freezes an immutable, hash-addressed case containing the nine-timeframe deterministic readout, source/freshness metadata, market structure, location/stretch, public order-flow/depth evidence, observed liquidation context, public derivatives context, attention/ranking context and the exact JEV decision/risk geometry available at entry time. Closing data later attaches the realized path (PnL/R, MFE/MAE, time-to-extremes, partial/trailing/stop events and available fee/funding income) without rewriting the entry snapshot.

## Data integrity

`case-memory.js` emits explicit quality flags instead of fabricating missing values. Missing/stale core 5m/15m data degrades the case snapshot; auxiliary unavailable sources remain explicit. Frame timestamps, synthetic-frame markers, stream age and any available kline-gap counters are retained. The main existing BrainHub data-quality gate remains authoritative for execution.

## Observable microstructure, not hidden intent

The case engine can label public-data observations such as sweep/reclaim, breakout acceptance/failure, aggression absorption, delta/price divergence, liquidation cascade/flush, exhaustion, resting-liquidity persistence/pull and chase-after-expansion. These labels are evidence summaries only. They do **not** identify a market maker, prove spoofing/iceberg intent, or gain execution authority.

## Similar-case retrieval

Similarity is computed from state, not only a setup name: direction/lane/family, multi-timeframe trend/structure, stretch/chase state, range/RSI/ATR, CVD/depth/spread, derivatives, ranking/24h move and microstructure event overlap. The result deliberately carries both profitable and losing analogs/counterexamples. Small samples never auto-promote into a rule.

## Context budget

The JEV request hard cap remains 52 kB. R2544.19 uses a `CORE_MARKET_FIRST` budget policy: optional experience/OSS/cortex context is compressed before deterministic core market evidence. The request-size log records which optional sections were compacted and whether any market-compaction step was still required. Core 5m/15m data remains the highest-priority payload.

## Open-source reference provenance

Repositories are **read-only engineering/research references**. No repository becomes market evidence, strategy authority, execution authority, or self-modifying code. No vendor code is copied into BrainHub as part of R2544.19. License metadata was checked from GitHub repository metadata on 2026-09-30 before adding new entries.

## Safety boundaries

- `selfModify = false`
- `autoPromotionToRules = false`
- `executionAuthority = false`
- learning remains soft context
- deterministic risk/execution integrity is unchanged
- optional 9Router/OpenRouter/Headroom failures do not become JEV execution authority
