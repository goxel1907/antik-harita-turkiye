# R2544.25 — PASS-2 Dynamic Residual Budget

## Trigger
R2544.24 fixed the original PASS-2 static-schema blocker in a single detail-probe, but natural scheduler shadow traffic exposed insufficient headroom. Ten post-deploy PASS-2 samples produced 9 local hard-budget blocks; observed bytes ranged from 47,961 to 51,892 against a 48,000-byte hard ceiling and 46,000-byte PASS-2 target.

Worst observed R2544.24 sample:
- beforeBytes: 116,740
- used bytes: 51,892
- coreMarketPacket: 30,879
- record: 5,352
- questions: 6,056
- experienceMemory: 4,417
- coreTruthProtected: true
- blockReason: JEV_REQUEST_CONTEXT_TOO_LARGE

The failure was local pre-provider budgeting, not OpenRouter/9Router execution. The protected market packet was intentionally not deleted to make the request fit.

## Design
R2544.25 keeps the existing 42k PASS-1 target, 46k PASS-2 target and 48k hard ceiling. It adds PASS-2-only residual stages after normal optional and market compaction has revealed the actual byte cost of the current protected market packet.

Residual order:
1. PASS2_RESIDUAL_QUESTION_TIGHT
   - preserves every question ID and choice key;
   - removes repeated plan geometry prose from question criteria;
   - points trade-plan choices to the canonical executable plan geometry in state.record.executablePlanOptions.
2. PASS2_RESIDUAL_RECORD_TIGHT
   - applies only to the sovereign PASS-2 record shape (attention + executablePlanOptions);
   - preserves plan IDs, side/lane, entry, stop, TP1/2/3, invalidation and origin/basis;
   - compresses duplicated attention/evidence detail while retaining requested evidence identities.
3. PASS2_RESIDUAL_MEMORY_TIGHT
   - preserves measured totals and compact winner/loser counterexamples;
   - bounds verbose lifetime aggregates and lane digests;
   - remains soft context only, with no execution authority.
4. PASS2_RESIDUAL_OPTIONAL_FINAL
   - last target-oriented fallback for Cortex/dynamic knowledge/description/decision-contract prose only;
   - does not modify protectedCoreTruth().

Legacy/non-sovereign PASS-2 record shapes are not passed through the sovereign residual-record compressor. If an irreducible protected core remains above the hard limit, fail-closed behavior is preserved.

## Safety invariants
- MAX_DECISION_REQUEST_BYTES remains 48,000.
- PASS1_TARGET_BYTES remains 42,000.
- PASS2_TARGET_BYTES remains 46,000.
- protected current-market truth is hash-checked before/after compaction.
- R2544.21 sparse-flow/sampling-confidence semantics remain unchanged.
- JEV remains final decision authority.
- Scanner remains attention-only.
- Execution, Binance transport, risk, stop/TP and position-management logic are unchanged.
- Provider routing and 9Router/OpenRouter-free helper behavior are unchanged.

## Regression coverage
R2544.25 adds natural-worst-class and stress fixtures around a ~31k to ~33k coreMarketPacket. Tests verify:
- PASS-2 <=46k for the observed worst-class distribution;
- >2k hard headroom in the ~31k-core fixture;
- choice IDs/keys survive residual question compaction;
- executable plan price geometry survives residual record compaction;
- measured totals plus winner/loser counterexamples survive residual memory compaction;
- verbose lifetime aggregate payloads are bounded;
- protected market truth remains byte-equivalent;
- legacy irreducibly oversized requests still fail closed.
