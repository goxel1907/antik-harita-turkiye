# R2544.19 Contextual Episode Memory

Date: 2026-09-30

## Goal

JEV remains the only strategic decision owner. R2544.19 improves what JEV is told and how its own measured trade history is recalled. It does not add a score gate, a 2-of-3 rule, an automatic veto, self-modifying strategy code, or a hidden "market maker" oracle.

## Market truth contract

Every JEV decision continues to receive deterministic 5m/15m core frames plus 1m/3m timing context, higher-timeframe context, order flow, depth, derivatives and observed Binance force-order liquidations. R2544.19 adds explicit provenance labels so JEV can distinguish:

- deterministic closed-candle numeric truth,
- forming-candle context (never confirmed structure),
- synthetic 45m context,
- CVD coverage/source,
- derivatives source/as-of/bucket age,
- observed liquidation evidence versus any unobserved heatmap,
- participant identity = NOT_IDENTIFIED,
- participant intent = NOT_ASSERTED.

## Contextual episode memory

Each live entry already stores an entryContext.marketSignature. R2544.19 expands future entry signatures and converts both historical entry signatures and the CURRENT market into the same compact episode fingerprint.

The fingerprint includes, when observed:

- 5m/15m trend, BOS/swing state, pattern/sweep labels, stretch/chase/squeeze/displacement/effort context;
- CVD direction/coverage;
- depth imbalance and spread bucket;
- OI delta, funding, taker buy/sell ratio, top-trader and global long/short positioning;
- observed long/short liquidation pressure.

For a new decision, JEV is shown nearest historical winners AND nearest historical losers. Similarity is contrastive evidence, not a prediction. JEV must compare what is materially different now before reusing a lesson. The same setup is allowed to have both winning and losing precedents.

## "Avladım / av oldum" semantics

BrainHub does not claim a hidden participant identity. It records observable mechanics such as sell-dominant CVD, ask-heavy depth, falling OI, taker sell dominance, long-liquidation pressure, sweep/reclaim, extreme stretch and confirmed/forming patterns. JEV may reason about a liquidity trap or squeeze mechanism from those observations, but cannot state that a specific market maker intentionally caused it.

## Open-source research registry

R2544.19 keeps the existing curated engineering references and adds:

- binance/binance-connector-python — MIT — official Binance API/WebSocket semantics and derivatives connector reference.
- bmoscon/cryptofeed — AGPL-3.0-or-later — normalized exchange feed, L2/trades/funding/OI/liquidation capture/replay architecture. Reference-only; code is not copied.
- AI4Finance-Foundation/FinRL — MIT — offline train/test/trade and adaptive-learning research reference. It does not become a live self-modifying authority.

Office now exposes every curated repository with its license, roles, why it exists, and the exact path by which a repo can influence JEV:

repo hint -> optional research worker -> source fetch/grounding -> JEV ACCEPT_REFERENCE review -> VERIFIED_REFERENCE in jev-knowledge.json -> PASS-1/PASS-2 dynamicKnowledge.

Repository code never becomes an order signal by itself.

## Safety invariants

- Current numeric market evidence outranks history.
- Similar past loss does not veto a trade.
- Similar past win does not authorize a trade.
- Learning never changes capital, leverage, stop rules, kill switches or execution integrity.
- JEV remains final strategic authority.
