# R2544.33 - Free worker evidence routing

A successful 9Router catalog with no OpenCode free routes previously revived the configured bootstrap list. This retried disconnected models. The successful catalog is now authoritative, including an empty pool. Invalid HTML or a malformed catalog remains a discovery failure and does not erase the last valid result. Unknown paid OpenCode IDs are excluded from the helper pool.

OpenRouter refresh removes stale direct routes even when the catalog contains no qualifying free models. The zero-price router remains available as a bounded fallback. The existing account quota, per-minute limits, maximum attempts, persistent cooldown and zero-price provider constraints remain in force. A task with a recent successful schema-validated response gains routing priority. Schema validation does not establish factual correctness, profitability or specialist training.

Both providers share evidence instructions for fast events, scalp, structure/price action, patterns, microstructure, regime, risk and finance/crypto research. Finance topics still follow the existing fetched-source and JEV-accepted knowledge workflow. These are task instructions, not additional agents, votes, trading decisions or mandatory timeframe agreement.

Plan watchers now carry the same numeric chart overlay selection as Office/JEV for cached timeframes, selected-frame FVG/OB/Fib/OTE levels, closed candles and per-frame provenance. Trend and rejection states retain their original timestamps and numeric values. This performs no additional Binance request. The stale Vision/V110 watcher identity was replaced with the current JEV evidence contract. Invalid or duplicate worker state fields, missing confidence and invalid/missing recheck timeframes fail validation.

Deployment includes the new `worker-expertise.js` module and verifies R33 release features. Runtime target: `R2544.33-JEV-FREE-WORKER-EVIDENCE`; Office target: `2.5.13-R2544.33-JEV-Brain`. APK code/API is unchanged.

Validation: 668/668 local tests passed, including seven new routing/provenance/schema cases. JavaScript and PowerShell syntax checks and `git diff --check` passed. Version-only assertions were aligned with the new release; synthetic provider test IDs were made explicitly free. No expected trading behavior was relaxed to make tests pass.

Deployment, authenticated account quota, live provider inference and device installation require separate verification. Public catalog membership is not evidence of successful inference. JEV remains the sole strategic authority; LIVE/OTO and existing positions remain under user control.
